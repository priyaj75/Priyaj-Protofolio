# 🌐 Personal Portfolio Website

Welcome to my personal portfolio website!
This project is designed to showcase my skills, projects, education, and personal information in a simple and attractive way.

## 🚀 About the Project

This portfolio website was created using **HTML, CSS, and JavaScript**. It provides an overview of my technical skills, projects, and contact information.

The main goal of this project is to create a clean, responsive, and user-friendly portfolio that represents my work and development skills.

* **HTML5** – Used to create the structure of the website
* **CSS3** – Used for styling, layout, animations, and responsive design
* **JavaScript** – Used to add interactivity and dynamic functionality
